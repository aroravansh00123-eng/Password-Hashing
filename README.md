# 🔐 Password Hashing Tool

A simple Python-based cybersecurity project that demonstrates how passwords can be converted into cryptographic hashes using **SHA-256**.

This project was created to understand the fundamentals of **password hashing, cryptographic functions, and basic password security** using Python.

---

## 📌 About the Project

Passwords should never be stored as plain text.

Instead, applications can transform passwords into a fixed-length hash using a cryptographic hash function.

This project demonstrates that concept using Python's built-in `hashlib` module and the **SHA-256** algorithm.

---

## ✨ Features

- 🔐 Password hashing using SHA-256
- 🐍 Built with Python
- 💻 Command-line interface
- 🧩 Simple and beginner-friendly implementation
- 📚 Demonstrates basic cryptographic hashing concepts
- 🚀 No external libraries required
